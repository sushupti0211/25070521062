# To Do List App

- **client** – React (Vite)
- **server** – Node.js (Express) API
- **database** – MongoDB (local, `mongodb://localhost:27017`, db `todoDb`)

## Run

```
cd server
npm install
npm start
```

```
cd client
npm install
npm run dev
```
evrything is working after setting up mongodb compass after installation as mentioned commands
